✂️ Substring Extractor
Challenge
Level: Easy

🧠 Task
You are given a string like this:
"abshvjngsh"

Write a function that takes three parameters:

a string input,

a startIndex,

an endIndex,

and returns a new substring from the original string based on the given indices.

✅ Example
input := "abshvjngsh"
startIndex := 2
endIndex := 7

Expected output:
"shvjng"
