# 🔡 String Character Printer

### 🧩 Challenge: Easy

Write a function that takes a string as input and prints the characters **step by step**, first building up and then reducing the string.

---

## ✏️ Description

Given a string, the function should output:

1. An incremental build-up of the string — one character at a time
2. Then, a step-by-step reduction back down to the first character

---

## 📌 Example

For the input string `"Coddy"`, the output should be:

```
C
Co
Cod
Codd
Coddy
Codd
Cod
Co
C
```
