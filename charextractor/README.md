🔍 Extract Characters from a String
Challenge
Level: Easy

Write a function that extracts and returns a substring from a given word, starting from the first occurrence of a specified start character and ending at the first occurrence of a specified end character.

🧠 Task
Given:

A string word

A startChar (the character to start from)

A lastChar (the character to end at)

Return a new string that begins at the first occurrence of startChar and ends at the first occurrence of lastChar.
