# ✂️ String Tokenizer

**Challenge Level:** Easy  
**Language:** Go 🐹

---

## 📌 Description

A simple Go function to split a string into tokens of equal length based on a given delimiter (chunk size).

---

## 🧠 Task

### You are given:
"cooddypythongolang"

### Expected output: 
"cooddy", "python", "golang"
