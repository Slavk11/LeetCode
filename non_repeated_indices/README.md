# 🧩 Non Repeated Indices

**Challenge**: Medium  
**Language**: Go (Golang)

## ✨ Description

You are given an array of strings like this:

```go
[]string{"a", "fc", "ab", "a", "ab", "b"}

Write a function that returns the indices of the elements that appear only once in the array.

✅ Example

Input:
[]string{"a", "fc", "ab", "a", "ab", "b"}

Output
[]int{1, 5}
