# 🧮 Sum

## 💡 Challenge — *Easy*

We are given an array of integers like:

```go
[2, 4, 6, 7, 8, 8, 9]

🧩 Task

Write a function in Go that:
Calculates the sum of:
the first element
the middle element (only if the array has an exact center)
the last element

If the array does not have a middle element (i.e. its length is even), return -1.

Input:  [2, 4, 6, 7, 8, 8, 9]
Output: 18
