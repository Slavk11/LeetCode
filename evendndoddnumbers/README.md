# 🔢 Even & Odd Numbers

## 💡 Challenge — *Easy*

We are given an array of integers:

```go
[20, 6, 78, 89, 9, 12, 33]

🧩 Task
Write a function in Go that:

Iterates through the array

Adds all even numbers

Multiplies all odd numbers

Returns the final result as:
sum of even numbers + product of odd numbers

✅ Example
Even numbers: 20 + 6 + 78 + 12 = 116  
Odd numbers:  89 * 9 * 33 = 26433  
Result: 116 + 26433 = 26549
