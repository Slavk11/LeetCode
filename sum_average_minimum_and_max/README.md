# 📊 Sum, Average, Minimum and Max

## 💡 Challenge — *Easy*

Given an array of floating-point numbers like:

```go
[3.5, 2.34, 8.9, 1.6, 4.3]

🧩 Task
Write a function in Go that:

Calculates the sum of all elements

Computes the average

Identifies the minimum and maximum values

📌 The output should print the results in the following order:
sum, average, min, max

✅ Example Output
20.64 4.128 1.6 8.9
