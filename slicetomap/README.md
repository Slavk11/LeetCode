# 🧠 Slice to Map

## 💡 Challenge — *Easy*

Given a slice of strings, write a function in Go that returns a **map**, where:

- Each **key** is a string from the slice
- Each **value** is the **length** of that string

---

### 🧩 Example

```go
Input:
[]string{"Coddy", "LearnGolang", "LearnPython", "Challenges"}

Output:
map[Challenges:10 Coddy:5 LearnGolang:11 LearnPython:11]
