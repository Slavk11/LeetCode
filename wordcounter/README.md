## 📝 Word Counter

### 🎯 Challenge Level: Medium

Create a function that counts the number of words in a given sentence.

---

### 📘 Problem Statement

You are given a string like:

```
"Learn Golang with Coddy"
```

Your task is to write a function that returns the number of words in this string. Words are separated by spaces.

---

### ✅ Requirements

* The function should take a single string as input.
* It should return the number of words in that string as an integer.
* Words are separated by one or more spaces.
* Ignore leading and trailing spaces.

---

### 💡 Example

```
Input:  "Learn Golang with Coddy"
Output: 4
```

Explanation: The string contains four words — "Learn", "Golang", "with", "Coddy".
