🧩 String Tokenizer
### Challenge Level: Easy
### Language: Go

✨ Description
Given a continuous string such as:
"cooddypythongolang"

Write a function that tokenizes (splits) the string into chunks based on a specified delimiter — which defines the length of each token. The function should return a slice (or list) of tokens.

📥 Input
A string input — the string to be tokenized.

An integer delimiter — the fixed length of each token.

📤 Output
A slice of substrings (tokens) of length delimiter.

✅ Example

## input 
```
input := "cooddypythongolang"
delimiter := 6
```
## Output:
```
delimiter := 6
```
